# CekBMIku — Aplikasi Pemantauan Body Mass Index (BMI)

CekBMIku merupakan aplikasi mobile berbasis Flutter yang dikembangkan untuk membantu pengguna menghitung Body Mass Index (BMI), memantau riwayat pemeriksaan, menetapkan target BMI, serta memperoleh informasi kesehatan dan rekomendasi gaya hidup berdasarkan kategori BMI.

Proyek ini dikembangkan menggunakan Laravel REST API sebagai backend, MySQL sebagai database, Website Admin untuk pengelolaan konten, serta Firebase Cloud Messaging (FCM) untuk mendukung sistem notifikasi.

## Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| Flutter & Dart | Pengembangan aplikasi mobile |
| Laravel | REST API dan Website Admin |
| MySQL | Penyimpanan data aplikasi |
| Firebase Cloud Messaging | Push notification |
| Docker | Lingkungan pengembangan backend |
| Figma | Perancangan UI/UX |
| Git & GitHub | Kolaborasi dan version control |

## Fitur Utama

- Registrasi, login, dan pengelolaan profil pengguna.
- Kalkulator BMI dan informasi kategori BMI.
- Riwayat pemeriksaan dan grafik perkembangan BMI.
- Penetapan target BMI serta pemantauan ProgressBMIku.
- Artikel Kesehatan dan Rekomendasi Gaya Hidup.
- Pengingat pemeriksaan BMI dan notifikasi perubahan status target.
- Website Admin untuk pengelolaan konten dan pemantauan aktivitas pemeriksaan BMI pengguna.
